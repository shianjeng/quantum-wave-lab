# Changelog

The version of the `qwave` package (pyproject.toml). The reference data in `reference/` belong to the
version they were exported with; a port should name the version it is tested against.

## 0.3.0 — 2026-09-24

### Added
- Gross–Pitaevskii / nonlinear Schrödinger equation: `Solver(..., nonlinearity=g)`, with exact
  nonlinear half-steps; a warning and a `diagnose` check for the stability limit Δt·k_max²/2 < π.
- Condensate ground states: `ground_state(..., nonlinearity=g)`, with a symmetric imaginary-time
  step (O(dτ²) fixed point); `Solver.chemical_potential`.
- `qwave.observables`: probability current and `FluxDetector` (spectral or 4th-order finite
  difference, optionally one slit), fed by the new `Solver.step(..., callback=, every=)`.
- `sech2_barrier` and its exact transmission `T_sech2`; analytic bright soliton, soliton energy,
  1D Thomas–Fermi chemical potential.
- `export_reference.py` and `reference/`: golden files for the C++/WASM port (5 cases, float64 and
  float32 tolerances), checked by `tests/test_reference.py`.
- `demo_gpe.py`: soliton collision and BEC interference (`figures/gpe.png`).
- Validation panels 10–12 (flux detector, bright soliton, GP ground state) and a mirror-symmetry
  check of the double slit; 24 checks in total.
- `validate.py --quick` (all checks, no figure) and `--jobs N` (process pool).
- `docs/` (method, validation, porting) and this changelog.

### Changed
- Slit openings are now the w/Δy cells symmetric about each centre: width, separation and mirror
  symmetry are exact. This requires (2·centre + width)/Δy to be odd, and a clear error is raised
  otherwise. The default and demo slit width is 1.125 (was 1.25). Previously the whole pattern sat
  half a cell below y = 0, and a packet at y = 0 sent ~4 % more probability through one slit.
- Imaginary time starts the ground state from a nodeless envelope (double well: 78 s → 8 s).
- `validate.py` restructured into one function per panel. The tunneling panel runs on a smaller box:
  the full validation takes 25 s on 4 cores (was 205 s).
- The README was shortened; details moved to `docs/`, and `--update-readme` became `--update-docs`.

## 0.2.0 — 2026-09-23

### Added
- Stationary states by imaginary-time propagation (`qwave/eigen.py`).
- Time-dependent potentials `V(t)`; single precision (`dtype=np.complex64`) with
  `renormalize_every`; `Solver.diagnose`; `set_dt`.
- Potentials `rect_barrier` (1D/2D, optional tanh edges), `slits`, `cosine_lattice`, `tilt`;
  `paint_disk(mode="set"/"add")`.
- Validation panels for the double-slit fringe period, Bloch oscillations, eigenstates, convergence
  order, single precision and absorber residual; README tables generated by `validate.py`.
- `pyproject.toml`, ruff, a CI matrix for Python 3.10–3.13.

### Changed
- Adjacent potential half-steps are merged for static potentials.
- The absorber is built by the `Solver` for its own Δt (a precomputed mask is rejected).
- Demos: double slit at Δt = 0.005 (V·Δt = 1 at the walls), stronger absorber; the GIF is simulated
  on a 56 × 56 box and shows the central 40 × 40.

## 0.1.0 — 2026-09-23

- Split-step Fourier solver (1D/2D) with absorbing boundary, potentials, analytic references,
  validation against analytic results, 2D demos, README GIF and CI.
